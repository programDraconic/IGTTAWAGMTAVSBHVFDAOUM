# Presentations Folder


Each team-lead number has the responsibility to add their contributions to the Presentations folder in the TL#-L# format.

Steps are simple:

1 - Create new subfolder with your team lead #, a dash, and the lecture number.
 e.g. TL1-L1, TL<#>-L<#>

2 - Populate with content (Slides, Videos, Lecture Materials)

3 - Profit. Thanks!
